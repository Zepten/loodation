# Loodation Mini App

Демо-каталог мини-игр с русским интерфейсом, адаптивной навигацией и условными игровыми очками. Приложение работает в обычном браузере и не требует Telegram, API или регистрации. Все данные хранятся только в состоянии страницы; платежей и реальных денег нет.

## Локальный запуск

Нужен Node.js 22.13 или новее и pnpm 11.

```sh
cd loodation-miniapp
pnpm install
pnpm dev
```

Vite напечатает адрес preview `http://localhost:8002`. Если этот порт занят, приложение сообщит об этом и не станет незаметно переключаться на другой. Production-сборка: `pnpm build`.

## Docker

Из корня репозитория соберите и запустите только Mini App:

```sh
docker compose -f compose.miniapp.yaml up --build
```

Откройте `http://localhost:8002`. Порт меняется переменной `MINIAPP_PORT`. Это отдельный compose-файл: backend и его переменные окружения для демо-интерфейса не нужны.
